# HOROS PROBE-1 — Stage 3.7C.4 Security Control Matrix

## 1. Security Control Mapping

| Control ID | Control Name | Security Objective | Implementation Mechanism | Verification Status (Subprocess) | Verification Status (OCI/Namespaces) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **ISO-UID-01** | Worker Identity & Privilege Escalation Restrictions | Prevent worker from acquiring elevated privileges. | `prctl(PR_SET_NO_NEW_PRIVS)`, `setuid(0)` denial probe on POSIX; token membership verification on Windows. | `PARTIALLY_VERIFIED` (Windows) / `TESTED_AND_VERIFIED` (Linux) | `TESTED_AND_VERIFIED` |
| **ISO-FS-01** | Read-Only Root Filesystem & Checkpoint Mount Writability Denial | Prevent persistence, weight tampering, or filesystem modification. | `--read-only` root, `ro` volume mount. Bound non-destructive write probes to candidate root and checkpoint paths. | `PARTIALLY_VERIFIED` (Root denied, temp ckpt writable) | `TESTED_AND_VERIFIED` |
| **ISO-VAULT-01** | Multi-Route Private Vault Invisibility & Traversal Denial | Ensure private evaluation vault remains invisible to inference worker. | Zero vault mount, deny ACLs, clean env, closed file descriptors. Multi-route inspection: direct, relative, symlink, procfs, mount, env, handle. Conclusive classification: `DENIED`, `NOT_FOUND`, `UNSUPPORTED`, `INCONCLUSIVE`. | `PARTIALLY_VERIFIED` (Direct/relative denied; procfs unsupported on Windows) | `TESTED_AND_VERIFIED` |
| **ISO-NET-01** | Kernel Network Namespace Isolation & Dropped Capabilities | Deny outbound network egress and covert channel exfiltration. | `--net=none`, `unshare -n`, drop `CAP_NET_RAW` / `CAP_NET_ADMIN`. Active TCP (8.8.8.8), DNS, HTTP, and raw socket probes. | `PARTIALLY_VERIFIED` (Proxy blackholing active) | `TESTED_AND_VERIFIED` |
| **ISO-RES-01** | Resource Quota & Limit Enforcement Schema (Cgroups v2) | Prevent resource exhaustion, fork bombs, and CPU/memory starvation. | Cgroups v2: `cpu.max` (2.0 cores), `memory.max` (2 GB = 2147483648 B), `pids.max` (128). Distinguishes configured, observed, and enforced. | `PARTIALLY_VERIFIED` (Configured recorded; cgroups unavailable on host Windows) | `TESTED_AND_VERIFIED` |
| **ISO-IPC-01** | Safe Binary IPC Protocol (HIPC) & Negative Frame Rejection | Eliminate pickle deserialization and parse malformed/oversized payloads fail-closed. | HIPC length-prefixed safe binary stream. Rejection of pickle magic, oversized frames (>64MB / >1MB header), corrupted magic, and unauthorized commands. | `TESTED_AND_VERIFIED` | `TESTED_AND_VERIFIED` |
| **ISO-REPLAY-01** | Cryptographic Nonce Tracking & Replay Attack Denial | Prevent score manipulation via request replay. | Unique per-request nonce tracking enforced independently on both evaluator client and in-worker loop. | `TESTED_AND_VERIFIED` | `TESTED_AND_VERIFIED` |
| **ISO-GOV-01** | Categorized Research Governance Invariants & Physical Quarantine | Maintain strict invariants, permanent holdout quarantine, and zero training execution. | 4-part categorized invariants: runtime-verified, static policy, physical quarantine, production authorization. Permanent exclusion of Stage 3.5 holdout. | `TESTED_AND_VERIFIED` | `TESTED_AND_VERIFIED` |
| **ISO-CRYPTO-01** | Ed25519 Cryptographic Provenance & Digest Anchoring | Bind all empirical evidence, candidate weights, runtime identity, and commit SHA into tamper-proof record. | Canonical UTF-8 JSON hashed with SHA-256 and signed via Ed25519 using dedicated non-production test key (`TEST_NONPROD_PUBLIC_KEY`). | `TESTED_AND_VERIFIED` | `TESTED_AND_VERIFIED` |
